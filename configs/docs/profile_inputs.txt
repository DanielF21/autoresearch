Cost of nx.clustering(G) on each of the five inputs it is timed on,
at networkx c94928ed9489, the base commit for every attempt.

Absolute times are from one machine and will differ in your box. What
carries over is the ratio between the inputs: the same call spans three
orders of magnitude across them, because the stock implementation's cost
scales with degree. A change with a fixed setup cost of a few milliseconds
is free on the first input and is the entire runtime of the fourth.

The hot function dominates at every input, so the same code is worth
optimising throughout. It is the cost of the work around it that changes:
448x between the first input and the fourth.

The flat and caller profiles in the other two documents are of the first
input only, which is the one slow enough for a profile to resolve.
